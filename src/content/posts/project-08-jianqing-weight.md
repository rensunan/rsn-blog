## 项目简介

见轻是一个体重管理工具，核心判断是：**减脂失败大多不是不知道方法，而是记录太累**。所以它把「每天要填多少东西」压到最低——三餐和训练计划一次设好，之后每天只需要点确认；体重只记一个数，趋势由 7 日均线说话。

线上地址：[tizhong.app.workbuddy.host](https://tizhong.app.workbuddy.host/?sharecode=C5CGC6YZNN)，手机打开即可用，不装 App。

原生 HTML/CSS/JS 实现，没有框架、没有构建步骤；账号与数据同步走 WorkBuddy Cloud（Postgres + Auth）。

## 功能

| 模块 | 说明 |
|---|---|
| **今日** | 体重（7 日均线）、热量三段式（目标 / 已摄入 / 还可吃）、今日训练、今日三餐 |
| **动作库** | 900+ 动作，按部位、器械、场地、冲击、目标筛选，示范图与动作要点齐备 |
| **趋势** | 体重曲线、热量摄入柱状图、打卡热力图，全部手写 SVG |
| **方案** | 目标体重与期限、三餐预设、每周训练模板与频率 |
| **我的** | 账号、身体参数、分享图、自定义食物 |

三个主要界面长这样：

![今日页](/images/jianqing/jianqing-today.png)

**今日页**：体重 7 日均线 + 打卡、热量三段式额度（目标 / 已摄入 / 还可吃）、今日训练、今日三餐各占一张卡。游客状态下整套都能体验。

![趋势页](/images/jianqing/jianqing-trend.png)

**趋势页**：体重曲线同时画实测、7 日均线、计划线与目标线四条参考；热量进出按天成柱；打卡热度成日历。

![方案页](/images/jianqing/jianqing-plan.png)

**方案页**：训练模板 + 频率（按周 / 按月 / 改次数），下面的每周计划自动排好，改次数或换模板立即重铺，不用手动调整。

几个具体设计：

- **热量额度按目标反推**，不是给一个通用数字：输入起始体重、目标体重、期限，算出每日应摄入多少，并按早/午/晚分配成三段。
- **三餐预设**：早餐固定吃什么、午餐晚餐各多少 kcal 都先设好，每天只要「确认」或「再加一点」。
- **训练按周模板**：选模板 + 频率（每周几次 / 每月几次），系统自动把这一周的动作铺好，今天该练什么直接显示，休息日就说休息日。
- **游客可用**：不注册也能把整套流程走一遍，数据只在内存里，刷新恢复样例。

## 设计要点

**先算安全边界，再算目标。** 按 7700 kcal/kg 反推每日缺口是最容易的部分，难的是不能让它算出「每天只吃 800 kcal」这种数字。所以引擎里叠了三层护栏：单日缺口封顶（减脂 750 / 增肌 500），减脂摄入不低于安全下限（女 1200 / 男 1500），低于基础代谢 85% 直接警告；同时校验速率——减重不超过体重 1%/周、增重不超过 0.5%/周，超了就按健康速率倒推一个更现实的目标日期给用户。方案可以激进，但算出来的数字必须能长期执行。

**看趋势不看单日。** 体重单日波动 1~2 斤是常态，拿两天的差值判断成败只会制造焦虑。所以主界面显示的是 7 日均线，趋势页再用斜率算真实速率、配合打卡热力图看执行度。日波动仍可见，但不作为判断依据。

**把「记录」变成「确认」。** 传统饮食 App 的失败点是每餐都要搜食材、称重量、算热量。这里的做法是把重复决策前置：三餐预设一次性定好，之后每天进入今日页只需要点「确认」，吃的不一样才动「重记」。食材库每条都带「每 100g 营养 + 一份的标准克数 + 生活量词」，把克数翻译成「一碗」「一巴掌」，减少称重依赖。

**动作库要能当字典翻，不只是排课。** 900+ 动作按部位分组、按器械和场地筛选，MET 值存入数据，选完动作直接按体重和时长换算消耗（`kcalOf(met, weightKg, minutes)`）。示范图走三级回退：云数据库的 base64 → 本地 `assets/ex` → CDN 镜像，任何一层缺失都不会出现破图。

**图表全部手写 SVG。** 体重曲线、热量柱状图、圆环、热力图、迷你条形图都是自己画路径，不引图表库——体积为零，离线可用，样式和全局设计语言一致。

## 技术栈

| 层 | 技术 |
|---|---|
| 前端 | 原生 HTML/CSS/JS，单页多视图，无框架无构建 |
| 数据 | WorkBuddy Cloud（Postgres + Auth）：档案、体重、训练、饮食、自定义食物五张表 |
| 计算 | 纯函数引擎（BMR / TDEE / 每日额度 / 均线斜率 / MET 消耗），不碰 DOM 与网络 |
| 图表 | 手写 SVG（曲线 / 柱状 / 圆环 / 热力图 / 迷你条） |
| 交互 | 自研滚轮选择器（弹层 + 吸附 + 多列）、底部弹层、Toast |
| 分享 | 结果卡片 SVG 绘制后转 PNG 保存 |
