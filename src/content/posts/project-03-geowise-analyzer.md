## 项目简介

基于大语言模型（DeepSeek）的岩土工程勘察报告智能解析工具，自动识别和提取 Word / PDF 文档中的表格数据（主表、备注、附表），支持表头对齐、去重和结构化输出。

## 功能特性

- **文档解析**：支持 `.docx` 和 `.pdf` 格式的岩土勘察报告
- **表格识别**：利用 LLM 自动识别主表、备注和附表
- **表头对齐**：基于语义相似度的表头自动对齐与合并
- **表格去重**：检测并去除重复表格
- **Web 界面**：Flask 驱动的浏览器端上传与结果查看
- **地下水提取**：自动识别地下水位、埋深等关键参数

## 设计要点

勘察报告里的表格是**不稳定结构**：同一张表在不同设计院、不同项目里，表头写法、单位位置、合并单元格方式都不一样，靠正则或固定模板提取必然失败。

因此这里把"理解表格结构"这件事交给 LLM：

1. 先用 `python-docx` / `PyMuPDF` 把文档里的表格和文本段落一并抽出来（**保留段落**是因为表头经常要靠上下文才能判断含义）；
2. 让 LLM 输出结构化的区域定位信息，划分主表 / 备注 / 附表；
3. 再做一层去重与表头标准化，把结果收敛成统一格式。

**为什么要去重和表头对齐**：跨页的同一张表会被解析成多段，表头里也常混着单位、编号、换行符。不做这一步，后面无论入库还是人工核对都是灾难。

## 技术栈

- **后端**：Python / Flask
- **AI 模型**：DeepSeek API（deepseek-chat）
- **文档处理**：python-docx / PyMuPDF
- **前端**：原生 HTML + JavaScript
