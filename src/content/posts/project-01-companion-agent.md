## 项目简介

一个温暖、善解人意的 AI 陪伴伙伴，具备长期记忆能力，能记住你的个人信息并在对话中自然引用。

## 核心能力

### 长期记忆

- **个人信息库**：自动识别并存储姓名、手机号、年龄、职业、爱好等，支持随时更新。
- **向量语义记忆**：所有重要对话自动存入向量数据库，能跨会话检索相关记忆。

### 短期记忆

- 滑动窗口保留最近 N 轮对话。
- 对话过长时自动摘要压缩，摘要同步存入向量记忆。

### 智能降级

- 优先使用本地 Ollama 模型（Echo-N1），低延迟、数据不出本地。
- Ollama 不可用时自动降级到 OpenAI 兼容 API。

### CLI 交互

- 基于 Rich 的美化终端界面。
- 内置命令：查看状态、个人信息、搜索记忆等。

## 设计要点

**记忆分层是这个项目的主线。** 短期记忆负责“当前这段对话别丢上下文”，长期记忆负责“上周说过的事这周还记得”，两者用不同的存储介质与检索方式：

- 短期 → 滑窗 + 摘要压缩，控制 token 消耗
- 长期 → 个人信息库（结构化）+ 向量库（语义检索）

**本地优先、云端兜底**，本质是在延迟、成本、隐私三者之间取一个可配置的平衡点：能本地跑就本地跑，跑不了再走 API。

## 技术栈

Python · Ollama / OpenAI 兼容 API · 向量数据库 · Rich CLI
