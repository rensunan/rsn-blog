## 项目经验

### 基于 RAG 与大语言模型的岩土属性预测系统　2025-06 ~ 2025-09　前后端开发

**技术栈**：Python、Flask、FAISS、Sentence-Transformers、LLM API、HTML/CSS/JS、TailwindCSS

**项目描述**：一套基于 RAG 与 LLM 的岩土工程文本智能分类系统。支持 Excel 批量输入土层描述文本，自动识别土 / 岩类别（淤泥、粉质黏土、花岗岩等 60+ 类别）并提取密实度、风化度、可塑度、湿润度等工程属性。系统实现「RAG 知识库构建 → 向量化索引 → 语义检索 → LLM 推理 → 缓存评估 → 动态更新」完整链路，解决传统人工分类效率低、标准不一致的问题。

**项目职责**：

- **RAG 知识库与向量索引**：构建覆盖 80+ 岩土类别的 JSON 知识库，采用 Sentence-Transformers 将文本转为 768 维向量，通过 FAISS 构建 IndexFlatL2 精确索引，实现毫秒级语义检索。
- **相似检索与动态阈值**：实现余弦相似度检索，动态下调阈值保证低相似度场景仍有参考案例；低于阈值的结果自动写入缓存库并记录检索计数。
- **LLM 提示词与双策略推理**：设计结构化提示词注入分类白名单与属性可选值，实现保守 / 冒进双策略推理，满足不同工程场景。
- **全栈 Web 开发**：Flask 实现文件上传、SSE 进度推送、Excel 逐行解析与结果回填；前端实现拖拽上传、方案选择与实时进度展示；支持预测结果自动转换为工程参数格式。

**项目成果**：批量处理数千条土层描述，效率提升 80% 以上；通过 RAG + 缓存 + 人工审核机制，知识库可持续积累，分类准确率逐步提升。

### EIP 表单自动化 MCP 服务（企业审批流程自动化）　2026-07 ~ 2026-10　后端开发

**技术栈**：Python 3.12、FastMCP（MCP SDK）、Starlette ASGI、OAuth2 鉴权中间件、Playwright、uv、pytest、Redis、MySQL、pandas / openpyxl

**项目描述**：一套面向企业信息门户（EIP）的审批流程自动化 MCP 服务。将内部报销、付款、合同、用印、出差、人资等审批表单的「获取下拉选项与 Schema → 组装字段 → 提交 / 保存」全流程封装为标准 MCP 工具，供 AI Agent 以自然语言直接调用，实现审批单据的自动填写、提交与列表筛选导出。服务以 ASGI 流式 HTTP 暴露，覆盖财务、协作、合同、销售、人资五大业务域共 54 个页面模块、113 个 MCP 工具，并提供从 HAR 抓包到 steps 模块的半自动化接入链路。

**项目职责**：

- **MCP 工具集设计与实现**：基于 FastMCP 封装 get 系列（表单下拉选项与 Schema，53 个）与 submit 系列（提交 / 保存，52 个）工具，统一 sync_post / base_payload / input_action_event 调用范式，按业务域与页面拆分 steps 模块，覆盖 54 个页面级表单。
- **鉴权与传输层**：以 OAuth2 鉴权中间件在请求头透传会话凭据，工具入参不落 token、手机号等敏感字段；服务通过 Starlette ASGI 应用以流式 HTTP 暴露，支持多客户端并发调用，并提供本地免鉴权调试开关。
- **表单解析通用化**：将人资付款、报销等页面的 Excel 参数解析逻辑抽取为通用可复用方法，使 HR 付款 / 报销 / 出差等多类表单复用同一套解析流程，减少重复实现。
- **HAR 到 steps 半自动化**：开发 eip-har-analyzer 技能，从浏览器 HAR 抓包自动提取接口路径、表单字段与下拉选项，半自动生成 steps 模块骨架，降低新表单接入成本。
- **列表筛选与导出改造**：主导「我已审批」列表按流程标题 / 事项类别 / 事项编号 / 办理时间筛选；将导出能力由返回 base64 改为一次性票据的限时下载链接，返回结构对齐既有 PDF 导出工具。

**项目成果**：服务覆盖 54 个页面模块、113 个 MCP 工具，配套 106 个测试用例保障回归；本人累计提交 149 次，占项目当前分支全部提交的 41%，承接了 54 个页面模块中的大多数表单对接及两次核心改造（列表导出重构、HAR 半自动化接入）。
